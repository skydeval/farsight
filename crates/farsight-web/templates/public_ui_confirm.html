Turn on the public UI?

Nothing has been changed yet. Read what becomes reachable, then confirm.

With the public UI on, anyone can open https://{{ e.hostname }}/ without logging in and see:

  • The instance hostname: {{ e.hostname }}.
  • The operator contact: the public pages do not show it. server.contact ({{ e.server_contact }}) is already public through getStats and the User-Agent of this instance's outbound requests.
  • When the index was last updated: one line at the foot of each page.
  • Incoming blocks for any account: which accounts block it.
  • Lists naming any account: the listblocked lists it is on, each with its name, owner and number of listblocks.
  • List memberships: the members of any indexed list, and the accounts that block the list.
    • {% if e.show_outgoing %}
  • Outgoing blocks: the blocks each account has made (show_outgoing_blocks is on).
    • {% else %}
  • The blocks an account has made are not listed (show_outgoing_blocks is off).
    • {% endif %}
  • Profile cards: for any account in a row, its handle, DID and the date the DID was created, fetched from the network when a visitor asks.{% if e.show_avatars && e.avatar_thumbnails %} The card has the account's avatar, which each visitor's browser fetches from Bluesky's image service (show_avatars and avatar_thumbnails are on): that service sees the visitor's address.{% else if e.show_avatars %} The card has the account's avatar, which each visitor's browser fetches from the account's own server (show_avatars is on): that server's operator sees the visitor's address.{% else %} Cards have no avatars (show_avatars is off); visitors' browsers contact only this instance.{% endif %}
    • {% if let Some(v) = e.record_viewer %}
  • Record links: block and listblock records link to {{ v }} (record_viewer_url).
    • {% endif %}
  • Removed records are not public. They stay on the history pages of the admin interface, after login.

{% if e.crawlable %}Search engines will be allowed to index the account and list pages (crawlable is on).{% else %}Search engines are asked not to index the pages (crawlable is off).{% endif %} Accounts that are not active, and the accounts in excluded_dids, are not shown.

/ on this hostname becomes the public home page; the dashboard stays at /admin.

You can turn the public UI off again at any time; caches in front of Farsight keep their copies for up to a minute.
