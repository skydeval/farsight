About this instance

What this is

This is Farsight {{ version }}, running at {{ c.hostname }}. Farsight is an independent index of public block records on the AT Protocol network. It is run by this instance's operator and is not affiliated with Bluesky.

Blocks on this network are public records in each account's repository. Farsight reads them and answers one question per account: who blocks it, directly or through a list.

What it holds

  • Blocks: one account blocking another.
  • Listblocks: an account blocking a whole list.
  • Lists: the name and purpose of each list.
  • List entries: the members of lists that at least one account blocks. Membership of other lists is not indexed.

How to read coverage

No index of a network this size is complete at every moment. Every section of every page says how much it can claim, at one of three levels.

Complete
The published definition, from the Farsight lexicon: "`complete` means that, for the response's scope, every record Farsight is not excluding is reflected as of `indexedAt`." and "The only exclusions are the ones counted in `exceptions`, and an exclusion stops being counted only when the excluded data has been re-listed." A section can be complete and still name a limit: that limit is what it leaves out.
Best effort
This instance has not finished reading the whole network. For this account it asked a backlink index — a separate service that records which records point at an account — and read what that index named. Records the index does not know are missing.
Partial
Some records are known to be missing or out of date. The reasons are listed next to the level.

"Reflects what this instance saw up to" a time means: everything the network published up to that time is included, within the level. "Page built" is when the page was made; a copy served from a cache keeps both times.

Limits a section can name

the event stream in use does not report repository resyncs
The feed this instance reads the network through leaves out one kind of event. Changes made that way are found only when accounts are read again.
the storage limit was reached
The operator's storage limit was reached and new records were refused for a time.
disconnected from the event stream
This instance is not receiving new records right now.
behind the event stream
This instance is receiving records later than they are published.
a gap in the event stream is being repaired
Records published during an interruption are being read again.
the first full pass over the network is not finished
This instance has not yet read every account's records once.
some lists are still being indexed
A list's members are being read; until that finishes they are not counted.
a list is stored only in part
A list is larger than this instance stores for one list.
a list could not be indexed
A list's record or members could not be read from its owner's server, or the list waits for storage.
the list is not indexed because nothing blocks it
Members are stored only for lists that at least one account blocks.
the backlink search was cut short
The backlink index named more records than this instance reads in one search.
this account's own records need re-reading
Something about this account's records could not be applied, and they are waiting to be read again.
another limitation
A limit this version of the pages has no words for. It is treated as partial.

What the removed-records pages show

They list records this instance stored and later removed: blocks, listblocks and list entries. {{ retention }} They are a record of what this instance saw, not a history of the network.

  • A block or membership that began and ended before this instance stored it is not there. This is most of what is missing.
  • Only lists that someone blocks are indexed; membership of other lists is never recorded. When a list stops being blocked its members are dropped without a record.
  • A removal this instance missed is recorded when it is noticed later, with the time it was noticed. Times stand still while the instance is disconnected from the network.
  • "First seen" is when this instance stored the record. It restarts when a list is indexed again.
  • Records of accounts that were deleted are removed, and accounts that are not active are not shown.
  • An account or list that removes very many records in a day has the excess left out.
  • A deleted list's members are recorded only up to that daily limit; a very large list is stored only in part.
  • Removed blocks of a list and removed members of a list are separate records. They can show that an account stopped blocking a list, and that someone was removed from a list, not that a given block covered a given account at a given time.
{% endif %}

Accounts that are not shown

Accounts that are not active — deactivated, suspended, taken down or deleted — are not shown on these pages: they have no page here and appear in no list of blockers, members or blocked accounts.
